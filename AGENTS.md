# Shared RimWorld context

For RimWorld API, XML definitions, mod lifecycle, saves, compatibility, or in-game testing work, read [the shared game reference](../GAME.md). Keep project-specific requirements in this repository and use TESTING.md for its validation procedures.

The shared reference lives outside this repository. If it is unavailable in a standalone checkout or worktree, use E:/Coding/Rimworld/GAME.md when accessible. Otherwise, report that shared context is unavailable and establish the needed facts from this project's configuration and version-matched sources.
